# Profile visuals

Original geometric artwork made for Khaled Alrefai's profile README.

- `engineering-lab.gif`: 40-frame, 4-second loop. Eye scan, system trace and data-network nodes are conceptual illustrations, not live measurements.
- `engineering-lab.png`: static alternative for reduced-motion preferences.
- `gswitcher-card.png`, `ddds-card.png`, `nibras-card.png`: project cards containing existing public project captures from Kaldx5/GSwitcher, Kaldx5/DDDS and Kaldx5/NIBRAS-Showcase respectively.
- `engineering-loop.png`: problem framing, experimentation, verification and iteration.
- `interest-map.png`: current interests, explicitly separating exploration from project work.

No artwork, animations or profile text were copied from other users. The source project captures retain their existing project context. NIBRAS design studies linked separately from the README contain demonstration data.

Images have text alternatives in the README. Key project information is repeated in searchable Markdown, so it is not available only inside images.
